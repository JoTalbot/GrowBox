# Схема подключения GrowBox

Контроллер: ESP32. Реле — active-LOW (`LOW` = включено).

## Силовая часть 220 V

```
ESP32 GPIO16 ──► IN1 реле ──► свет
ESP32 GPIO17 ──► IN2 реле ──► вытяжка + угольный фильтр
ESP32 GPIO18 ──► IN3 реле ──► обогрев
ESP32 GPIO19 ──► IN4 реле ──► обдув (циркуляция)
ESP32 GPIO15 ──► драйвер ШИМ диммера света (рассвет/закат)
```

Общий GND реле и ESP32 обязателен. Катушки реле питать отдельно, не с 3V3 ESP32.

## 12 V полив

```
ESP32 GPIO22 ──► IN5 ──► помпа
ESP32 GPIO23 ──► IN6 ──► клапан горшок 1
ESP32 GPIO25 ──► IN7 ──► клапан горшок 2
ESP32 GPIO26 ──► IN8 ──► клапан горшок 3
ESP32 GPIO21 ──► отдельное реле/MOSFET ──► увлажнитель
```

8-канальный модуль занят полностью. Увлажнитель — девятое реле на GPIO 21. Пока его нет, галочку на дашборде не ставь.

Полив: открыть клапан зоны → включить помпу (длительность в настройках, по умолчанию 8 сек) → закрыть.

## Датчики

| Датчик | GPIO | Логика |
| --- | --- | --- |
| DHT22 климат | 4 | температура / влажность / VPD |
| DS18B20 вода | 27 | OneWire, 4.7 кОм к 3V3 |
| Почва 1 | 32 | ёмкостной ADC |
| Почва 2 | 34 | ADC only, без внутреннего pull-up |
| Почва 3 | 35 | ADC only |
| Поплавок бака | 13 | INPUT_PULLUP, бак пуст = HIGH |
| Протечка | 14 | INPUT_PULLUP, протечка = LOW (замыкание на GND) |
| Сеть 220 V | 33 | INPUT_PULLUP, сеть есть = LOW через оптопару |

Почвенные датчики считаются отключёнными, если сырой ADC ≤ 100 или ≥ 4000.

## Калибровка почвы

На дашборде для каждого горшка:

1. Сухой субстрат → «0% Сухо»
2. После полива / во влажном субстрате → «100% Влажно»

Порог автополива: **28 %**.

## Первый запуск

1. Залить скетч по USB.
2. Подключиться к `Growbox-Setup` / `12345678`.
3. Указать домашнюю Wi‑Fi сеть.
4. Открыть http://growbox.local
5. Поплавок, протечку и датчик 220 V включать только после реальной проводки.
6. Дальше прошивать через `/update`.
