# Changelog

## 6.2 — 2026-08-12

- Ручной режим Авто/Вкл/Выкл для света, вытяжки, обогрева, обдува и увлажнителя
- Настройки расписания, климата, полива и VPD с дашборда (NVS)
- Увлажнитель GPIO 21: авто по коридору VPD, на цветении не увлажняет при низком VPD
- Telegram: /light /exhaust /heat /fan /humid /auto /settings
- Термозащита света перекрывает ручное «Вкл»

## 6.1 — 2026-08-12

Старт от прошивки, залитой в ESP32 (`Growbox_CriticalKush_V6`).

- Watchdog стартует после Wi‑Fi, а не до портала WiFiManager
- Контроль 220 V работает только при включённом флаге
- День цикла пишется после NTP, сброс с дашборда и `/resetday`
- Резервный полив без датчика почвы больше не зависает навсегда
- Метки полива сохраняются в NVS
- Telegram: URL-encode, проверка Wi‑Fi, сброс WDT на HTTPS
- Скетч лежит в нормальной папке Arduino IDE

## 6.0
