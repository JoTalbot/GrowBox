# Образы для OTA

## Шаг 1 — сервисный загрузчик

Файл: [GrowBox-OTA-Service.bin](GrowBox-OTA-Service.bin) (~773 КБ)

Залей его в **текущий** ElegantOTA: http://growbox.local/update

Он маленький, чтобы уложиться в 8-секундный watchdog старой прошивки.  
Watchdog в сервисе **выключен**.

После ребута открой http://growbox.local — должна быть зелёная страница **GrowBox Service OTA**.  
Если Wi‑Fi не поднялся: точка `Growbox-OTA` / пароль `12345678`.

## Шаг 2 — полная прошивка

Файл: [GrowBox-v6.3.bin](GrowBox-v6.3.bin) (1.2 МБ)

На сервисной странице выбери этот файл и жми «Прошить».  
20–60 секунд, питание не трогать.

В шапке дашборда появится **v6.3**. Дальше OTA снова через `/update`.
