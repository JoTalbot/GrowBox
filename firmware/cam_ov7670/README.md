# Второй ESP32 + OV7670 (не плата гроубокса)

1. Новый проект Arduino / PlatformIO, плата **ESP32 Dev Module**.
2. Библиотека: `esp32-ov7670` / примеры `ESP32_OV7670` (без FIFO). JPEG на лету почти нет — обычно RGB565 → свой энкодер или низкое разрешение.
3. Wi‑Fi как у гроубокса, веб `/capture`.
4. IP этого ESP прописать в гроубоксе: поле камеры / `camIp`.

Если нужна нормальная картинка в Telegram с улицы — OV2640 ESP32-CAM, не этот модуль.
