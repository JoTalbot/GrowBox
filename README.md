# GrowBox — Critical Kush Enterprise

Прошивка ESP32 для автоматического гроубокса: климат, свет с рассветом/закатом, полив трёх зон, безопасность и дашборд.

Текущая версия прошивки: **v6.3**  
Скетч: [`firmware/Growbox_CriticalKush_V6/Growbox_CriticalKush_V6.ino`](firmware/Growbox_CriticalKush_V6/Growbox_CriticalKush_V6.ino)

## Что умеет

- Стадии: вегетация 18/6, цветение 12/12, сушка 60/60
- Рассвет/закат 30 минут по ШИМ
- DHT22: температура, влажность, VPD
- DS18B20: температура воды в баке
- Три ёмкостных датчика почвы + калибровка сухо/мокро
- Dry-back полив 8 сек / зона, пауза промокания 45 мин
- Резервный полив раз в сутки, если датчик почвы отключён
- Вытяжка 24/7 на веге/цвете, импульс 30 сек / 10 мин на сушке
- Обдув 15 мин / пауза 5 мин (на сушке выключен)
- Обогрев: день 24.5 °C, ночь 20.5 °C, сушка 16 °C
- Аварийное отключение света при 32.5 °C
- Поплавок бака, протечка, опциональный контроль 220 V
- Ручное управление реле: Авто / Вкл / Выкл, авто не сбивает ручной режим
- Настройки света, климата и полива с дашборда, без перепрошивки
- Увлажнитель по VPD (GPIO 21), защита от плесени на цветении
- Telegram-бот, OTA, CSV за 24 часа, WiFiManager, watchdog

Дашборд после подключения к Wi‑Fi:

- http://growbox.local
- или IP контроллера в локальной сети
- OTA: http://growbox.local/update

Первый запуск без сохранённой сети поднимает точку `Growbox-Setup` / пароль `12345678`.

## Сборка

Arduino IDE 2.x, плата **ESP32 Dev Module**, ядро Espressif 2.0+ или 3.x.

Библиотеки:

- WiFiManager (tzapu)
- ElegantOTA
- DHT sensor library (Adafruit)
- Adafruit Unified Sensor
- OneWire
- DallasTemperature

Список: [firmware/libraries.txt](firmware/libraries.txt).

Открой `firmware/Growbox_CriticalKush_V6/Growbox_CriticalKush_V6.ino` и залей по USB. Дальше обновления — через `/update`.

## Удалённый агент за NAT

Входящий порт на ESP32 с улицы не открыть. Коробка сама ходит наружу:

- команды и телеметрия через [ntfy.sh](https://ntfy.sh)
- OTA: агент кладёт `.bin` на HTTPS и шлёт `ota <url>`
- либо `version.json` + команда `flash` / автопрошивка

Как включить и слать команды: [firmware/remote/README.md](firmware/remote/README.md).  
Скрипты: `tools/remote_cmd.py`, `tools/remote_status.py`.  
Сборка `.bin`: GitHub Actions → **Build firmware**.

## Что нового в v6.2

- На каждом реле кнопки **Авто / Вкл / Выкл**. Ручной режим пишется в NVS и переживает ребут. Термозащита света сильнее ручного «Вкл».
- Блок «Параметры»: расписание света, температуры, полив, VPD — сохраняется без USB.
- Увлажнитель: GPIO 21, галочка «подключён». Авто: VPD выше коридора — вкл, ниже (риск плесени) или RH ≥ 75% — выкл. На сушке молчит.
- Telegram: `/light on|off|auto`, то же для `/exhaust` `/heat` `/fan` `/humid`, плюс `/auto` и `/settings`.

## Что исправлено в v6.1

Отталкивались от файла, который сейчас залит в ESP32 (`Growbox_CriticalKush_V6`).

1. **Watchdog больше не убивает WiFiManager.** WDT 8 сек стартовал до портала настройки (до 180 сек) — контроллер мог крутиться в reboot-loop без сохранённой сети.
2. **Контроль 220 V не орёт вхолостую.** Флаг `enablePowerSense` читался из NVS, но игнорировался. Без оптопары пин в HIGH → ложная авария «нет сети» каждые 30 минут. Теперь датчик работает только после включения кнопкой «Датчик 220V».
3. **Счётчик дня цикла живой.** `cycleStartTimestamp` никогда не записывался — день всегда был 1. Теперь метка ставится после NTP, есть кнопка и команда `/resetday`.
4. **Резервный полив без датчика.** Если горшок без сенсора и `lastWateredTime == 0`, зона никогда не поливалась. Теперь 24-часовой таймер стартует с загрузки, метки полива пишутся в NVS.
5. **Telegram не роняет WDT.** Перед/после HTTPS сбрасывается watchdog, сообщения URL-кодируются, нет запроса без Wi‑Fi.

## Безопасность

- Поплавок и протечка по умолчанию выключены — включи, когда датчики подключены.
- Контроль 220 V тоже выключен, пока нет оптопары.
- Секреты Wi‑Fi и Telegram живут в NVS, не в репозитории.
- Реле active-LOW: в `setup()` сначала пишется `HIGH`, потом `pinMode`, чтобы не моргнуть нагрузкой на старте.
