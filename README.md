# GrowBox

Автоматизированная система управления гроубоксом: климат, свет, полив и мониторинг в одном проекте.

GrowBox собирает показания датчиков, держит целевые диапазоны температуры и влажности, управляет освещением и поливом по расписанию и отдаёт состояние через веб-интерфейс и API.

## Возможности

- Мониторинг температуры, влажности воздуха, влажности почвы и освещённости
- Управление светом, вентиляторами, увлажнителем, обогревателем и помпой полива
- Дневной / ночной цикл и профили выращивания
- Пороговая автоматика с гистерезисом (без дребезга реле)
- Журнал телеметрии и аварии (перегрев, сухая почва, отказ датчика)
- Локальный веб-дашборд и REST API
- Работа без облака: контроллер поднимает точку доступа, если Wi‑Fi недоступен

## Архитектура

```
[датчики] ──► ESP32 / Raspberry Pi ──► актуаторы (реле / MOSFET)
                      │
                      ▼
              локальный API + UI
                      │
                      ▼
              журнал / конфиг / профили
```

Планируемые модули:

| Модуль | Назначение |
| --- | --- |
| `firmware/` | Прошивка контроллера (датчики, реле, расписание) |
| `backend/` | API, хранение телеметрии, правила автоматики |
| `frontend/` | Дашборд: графики, ручное управление, настройки |
| `docs/` | Схемы подключения, BOM, калибровка датчиков |

## Железо (черновик BOM)

- Контроллер: ESP32 или Raspberry Pi
- DHT22 / BME280 — температура и влажность
- Ёмкостный датчик влажности почвы
- Датчик освещённости (BH1750 или аналог)
- Модуль реле 4–8 каналов (свет, вентилятор, увлажнитель, помпа)
- Блок питания 5 В / 12 В в зависимости от нагрузки
- Опционально: датчик уровня воды, TDS/pH, камера

Точные пины и схема появятся в `docs/` после первой рабочей прошивки.

## Быстрый старт

Репозиторий только что заведён. Сборка и прошивка появятся вместе с первым рабочим кодом.

```bash
git clone https://github.com/JoTalbot/GrowBox.git
cd GrowBox
```

## Конфигурация

Целевые значения и расписание будут храниться отдельно от прошивки, чтобы менять профиль выращивания без пересборки. Черновик параметров:

```yaml
climate:
  day:
    temperature_c: [22, 28]
    humidity_pct: [50, 70]
  night:
    temperature_c: [18, 24]
    humidity_pct: [45, 65]
light:
  on: "06:00"
  off: "00:00"
irrigation:
  soil_moisture_min_pct: 35
  max_run_sec: 20
```

## Безопасность

- Секреты (Wi‑Fi, токены, пароли) не коммитить
- Реле и силовая часть — только через опторазвязку и корректный номинал
- Помпа не должна работать «всухую»: нужен датчик уровня или жёсткий таймаут
